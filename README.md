# AI Study Planner 🚀

## 📌 Overview
This project helps students identify weak topics and generate a smart daily study plan.

## ⚙️ Features
- Add subjects and topics
- Classify strength (Strong / Medium / Weak)
- Detect weak areas
- Generate smart study suggestion

## 💡 How it works
The system prioritizes weak topics and suggests what to study first.

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
